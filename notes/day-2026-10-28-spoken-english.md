# Spoken English practice: 28 Oct 2026

Say each line aloud three times.

1. Can the supervisor create a post right on the schedule?
2. Put the new post after Maingate 2.
3. Can I delete it permanently, or only switch it off?
4. I changed his shift in the roster, but the schedule still shows the old one.
5. Please warn me before I publish a mistake.
6. I'd like a small table with today's totals on this page.
7. Each page should show who is logged in.
8. Why are there so many buttons? Keep only the daily ones outside.
9. What is the template for?
10. Is there anything important left before I show it to the manager?

| Say | Not |
|---|---|
| delete it permanently | permanently delete pannalama |
| still shows the old one | still showing old |
| who is logged in | login name show |
| before I show it to the manager | before manager kitta kodukkalama |
