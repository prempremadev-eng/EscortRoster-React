# Spoken English practice: 20 Oct 2026

Say each line aloud three times.

## About the work

1. Today we set up the auto fill post by post.
2. The teams change every month, but the small groups stay the same.
3. We go by who actually worked at the post last month.
4. The same guard should not stand in the sun two days in a row.
5. The guards are used to this order, so please don't change the sheet.
6. The connection is up, but the server won't let me run anything.

## Asking and explaining

7. Did you notice that something has changed here?
8. Which post does it start with first?
9. Can I keep working here if I run this command?
10. Please check whether it's connected or not.
11. Let's stop for today and try again tomorrow morning.
12. Fill yesterday's chart first, then today's.

## Small words to notice

| Say | Not |
|---|---|
| "two days **in a row**" | "two days continuously" |
| "they are **used to** it" | "they are use to it" |
| "**Which** post does it start **with**?" | "First which point it will start?" |
| "Is it connected **or not**?" | "It connected or not?" |
| "**schedule**" (SHED-yool / SKED-yool) | "sedule" |
